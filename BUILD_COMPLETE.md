## 📝 Configuration Guide

### Environment Variables

The `.env.local` file has been created with the following configuration:

```env
# Database (optional - only needed for full backend features)
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/auriona"

# Authentication
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="auriona-secret-key-change-in-production"

# AI APIs (optional - for advanced AI features)
ANTHROPIC_API_KEY="sk-ant-api03-your-key-here"
OPENAI_API_KEY="sk-your-openai-key-here"

# Master Control Center Settings
MCC_MONITORING_INTERVAL=300000        # 5 minutes
MCC_AUTO_SCALING_THRESHOLD=85         # 85% load
MCC_MAX_CONCURRENT_INFERENCES=100

# Quantum AI Settings
QUANTUM_AI_OPTIMIZATION_ITERATIONS=1000
QUANTUM_AI_TEMPERATURE_DECAY=0.99

# Autonomous Agent Settings
AGENT_SCAN_DEPTH=5
AGENT_CRITICAL_THRESHOLD=0.05
AGENT_OPTIMIZATION_INTERVAL=3600000   # 1 hour

# ML Orchestrator Settings
ML_MAX_BATCH_SIZE=32
ML_GPU_ENABLED=false
ML_AUTO_SCALE=true

# Deployment Agent Settings
DEPLOY_CANARY_PERCENTAGE=10
DEPLOY_HEALTH_CHECK_INTERVAL=10000    # 10 seconds
DEPLOY_AUTO_ROLLBACK_THRESHOLD=0.5    # 50% error rate
```
